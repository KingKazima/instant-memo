## 🎯 项目简介

**即刻备忘** 是一个为"零摩擦记录"而生的个人备忘工具。灵感来自 Google 搜索首页的极致简洁——打开网页、输入文字、按回车，3 秒内完成一次记录。

- ✨ **极简录入**：打开即聚焦输入框，回车即保存，无任何多余干扰
- ☁️ **云端同步**：基于 Supabase 实现跨设备数据实时同步
- 📱 **全端适配**：PC、平板、手机响应式布局，随时随地记录
- 🔒 **安全隔离**：Row Level Security 行级安全策略，数据仅自己可见

## 🛠️ 技术栈

| 层级 | 技术 | 说明 |
| :--- | :--- | :--- |
| **前端** | 原生 HTML5 + CSS3 + Vanilla JS | 零依赖，单 HTML 文件，极致轻量 |
| **BaaS** | Supabase | PostgreSQL 数据库 + 匿名认证 + RESTful API |
| **部署** | GitHub Pages / Netlify / Cloudflare Pages | 静态站点托管，全球 CDN 加速 |
